2. PROBLEM DEFINITION
================================================================================

Objective:
  Build a machine learning model to predict mobile phone price categories
  based on hardware specifications.

Business Context:
  - Mobile phone manufacturers need to price their products competitively
  - Understanding the relationship between specs and price is crucial
  - Automated classification helps in market analysis and positioning

Target Variable:
  price_range (Multi-class with 4 categories)
  - 0: Low Cost (Budget phones)
  - 1: Medium Cost
  - 2: High Cost (Premium phones)
  - 3: Very High Cost (Flagship phones)

Input Features:
  20 hardware specifications including:
  - Memory: RAM, Internal Storage
  - Performance: Clock Speed, CPU Cores
  - Camera: Front Camera, Primary Camera
  - Display: Screen Height, Screen Width, Resolution
  - Connectivity: 3G, 4G, WiFi, Bluetooth
  - Battery: Battery Power, Talk Time
  - Physical: Weight, Depth, Dual SIM

4. METHODOLOGY
================================================================================

Data Preprocessing:
  1. Data Loading: Read CSV files using pandas
  2. Data Validation: Check for missing values, duplicates, data types
  3. Exploratory Analysis: Generate statistics and visualizations
  4. Feature Scaling: Applied StandardScaler normalization
  5. Train-Test Split: 80-20 split with stratification

Model Selection Strategy:
  Trained 7 different algorithms to find the best performer:
  - Linear Models: Logistic Regression
  - Tree-based: Decision Tree, Random Forest, Extra Trees, Gradient Boosting
  - Distance-based: K-Nearest Neighbors (KNN)
  - SVM: Support Vector Machine with RBF kernel

Training Process:
  1. Initialize models with standard hyperparameters
  2. Train each model on training data
  3. Generate predictions on test data
  4. Calculate performance metrics
  5. Compare and select best model

Evaluation Metrics:
  - Accuracy: Overall correctness
  - Precision: True positives / (True positives + False positives)
  - Recall: True positives / (True positives + False negatives)
  - F1-Score: Harmonic mean of Precision and Recall
  - Confusion Matrix: Detailed classification breakdown

8. MODEL DEPLOYMENT
================================================================================

Production-Ready Assets:

1. Saved Model: models/best_model.pkl
   - Fully trained SVM model
   - Ready for making predictions
   - Size: ~150 KB

2. Feature Scaler: models/scaler.pkl
   - StandardScaler fitted on training data
   - Must be applied to new data before prediction
   - Size: ~2 KB

Usage Example:

```python
import pickle
import pandas as pd

# Load model and scaler
with open('models/best_model.pkl', 'rb') as f:
    model = pickle.load(f)
with open('models/scaler.pkl', 'rb') as f:
    scaler = pickle.load(f)

# Prepare new data
new_data = pd.read_csv('new_phones.csv')
new_data_scaled = scaler.transform(new_data)

# Make predictions
predictions = model.predict(new_data_scaled)

# Map to labels
labels = {0: 'Low', 1: 'Medium', 2: 'High', 3: 'Very High'}
for pred in predictions:
    print(f"Predicted price: {labels[pred]}")
```
